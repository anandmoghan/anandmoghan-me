App icons

The icon set for every app on anandmoghan.me, as installable tiles and as UI glyphs. Open this file from the repo so the tile images resolve.

The system

Every glyph is drawn on one 24-unit grid with its live area between 3 and 21. Strokes are 1.8 units with round caps and joins, and rounded rectangles use a 2.5 radius. Each glyph has one solid detail (a heart, a day, a dot, a ribbon) so it still reads at 16 px.

A tile is the same glyph at 12x on a 512 square with a 116 corner radius. The tile colour is the app's light accent from global/styles/tokens.css. The glyph is drawn in the paper colour #f7f4ef, and its one detail takes the app's dark-mode accent, so the two themes meet in every tile. Nila keeps its own character: a slate moon and a coral star on paper.

In the UI the glyph uses currentColor, so the hub tiles, the header and the roles page tint it with the area colour, which already switches between the light and dark tokens.

File What
public/apps/icons/<id>.svg Tile source, tracked.
common/apps/icons/<id>.tsx UI glyph, built on Glyph.tsx; index.ts maps app ids to glyphs.
scripts/build-app-icons.mjs Renders <id>-180.png, -192.png, -512.png and -maskable-512.png next to each tile. Runs before npm run dev and npm run build; the PNGs are gitignored.
public/apps/<app>/icons/<id>.svg Tile of a private app, in a gitignored folder; the build script renders it too.

The 180 px PNG is flattened onto the tile colour, because iOS draws transparent corners black. The maskable PNG is flattened the same way, since the launcher applies its own mask.

Maskable safe zone

Android may crop a maskable icon to any shape inside the central circle of 80 percent. Every glyph stays inside it with room to spare.
