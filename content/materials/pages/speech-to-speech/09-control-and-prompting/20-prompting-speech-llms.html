Prompting speech LLMs

A speech LLM takes several prompts at once, and each one controls a different property of the output. Persona text sets what the agent is, a reference clip sets who it sounds like, an instruction sets how it delivers a line, and the user's own audio nudges its prosody. The channels themselves are described in Control channels; this section is about how they combine in a live conversation.

Think of briefing a radio host. Before the show you agree the character and the voice, which stay fixed. During the show you pass notes ("warm, slightly slower") with each segment, and the host reacts to the caller's mood without being told.

How it works

Everything is context. The persona is text tokens ahead of the dialogue, and the voice prompt is audio tokens ahead of that, so the voice can be prefilled once. One duplex model concatenates a voice segment and a text segment into a hybrid system prompt, marks where it ends with delimiters, and masks the loss on that prefix during training. Style instructions work the same way: a description, an end token, then the content to speak. Speaker and style fields are randomly masked in training so the model copes when they are missing. The user's audio is streamed into the same context, and it shapes the response style and the prosody on re-entry after an interruption.

Some prompts are fixed and others vary. Persona and voice are set at session start, and one realtime API documents that the voice cannot change once the model has emitted audio. The per-turn lever is the style instruction. In a unified design, the reasoning LLM returns a short style field with each reply (for example "warm, slightly slower"), and the speech LLM treats it as a style instruction. The reasoning LLM never touches audio, so it can be swapped without retraining the speech model. The full wiring is in System design.

A model has to be trained to be steerable. One duplex model built on Moshi was fine-tuned on natural and synthetic dialogues covering instruction following, vocal delivery and reasoning, then tuned with two-stage reinforcement learning on hybrid rewards. Its benchmark has 390 spoken prompts and 1,067 binary rubrics covering tone, persona, style or accent, and speed or length. Supervised training raised the pass rate by 44.5 points over the strongest open baseline. The reward analysis also caught the model gaming the reward with incomplete responses; see Reward hacking and its guards.

Inference (design, not sourced)
  • Keep the style field to a few words.
  • Let the speech LLM adapt to the user's audio on its own; do not ask the reasoning LLM to guess mood from a transcript.
  • Guidance on the style condition would act as a strength knob; no source measures it for prompts.

Levers and optimisations

Lever What it changes Trade-off
Persona prompt wording Role and behaviour consistency Longer prompts cost context and can drift over a long call
Voice prompt choice and prefill Identity, and start-up cost A fixed, prefilled voice is cheap; changing voice mid-session is usually not possible
Prefix caching Latency of a long system prompt Needs a stable prefix
Style instruction per turn Delivery of the next reply Needs a model trained on instructions; short hints work best
Instruction-tuning data How faithfully hints are followed Labelling and synthetic-data cost
Prompt masking in training Robustness when fields are missing Slightly weaker control per field
User-audio adaptation Whether tone follows the caller Natural but hard to steer; can overshoot

What goes wrong

Instruction following is still the weak spot. In one benchmark of full-duplex systems, the best of six reached only about 64% adherence on turn-taking instructions, as scored by an LLM judge. Persona does not imply behaviour: another benchmark (1,038 cases from 240 conversations, eight assistant roles) found that obeying an explicit turn-taking rule did not mean a model could infer the rule from a persona. Models that settled harmless instruction conflicts often failed when a safety-relevant role should have overridden an explicit directive. A persona-conditioned model can also trail a stronger model on role adherence (author-reported).

Adaptation to the user's audio is brittle. When speech before and after an interruption was compared, one system sped up by about 19 words per minute and another by about 60 with falling pitch, which the authors call hurried and brittle.

Measuring all this is hard. Audio-LLM judges show verbosity and positional biases, so adherence scores need mitigation and human listening in the loop. Emotion-embedding similarity gives a second, cheaper signal. Leakage from voice prompts, unreliable tags and consent gating are covered in Control channels and Safety and provenance.

In the interview, say:

"I treat prompting as separate channels: persona text and a voice clip fixed per session, a short style instruction per turn, and the user's audio for adaptation. A reasoning LLM can emit a style hint with each reply and the speech LLM applies it. I would measure adherence with emotion similarity and calibrated judges, because instruction following is still the weak spot."
