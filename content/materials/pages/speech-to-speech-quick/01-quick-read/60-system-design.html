System design: voice agent and talking avatar

  • Inference Target: a unified speech LLM with a downstream text LLM (previous page). The cascade below is the baseline, launch fallback and comparison point.
  • A cascaded voice agent is three models plus turn logic, run as overlapping streams; latency comes from overlap, not any single model.
  • Inference Use WebRTC to the client (LiveKit and Pipecat package this) with a control data channel; persistent bidirectional streams between servers, with data and control planes separate.
  • Replace a bare VAD timeout with a semantic end-of-turn model, such as Pipecat's Smart Turn (docs) Reported. Inference It shifts the dead-air versus cut-off curve but does not remove it.
  • Inference Never feed raw partials to the LLM; start it at the end-of-turn candidate and cancel on change.
  • Inference Chunk LLM text for TTS with a small first chunk at a clause boundary, then full sentences.
  • Barge-in: cancel LLM and TTS, flush buffers, truncate context to what was actually played, return to listening. OpenAI's Realtime API exposes truncation as conversation.item.truncate (guide) Reported.
  • Echo cancellation is the precondition; the W3C echoCancellation property removes speaker sound from the microphone (W3C spec) Confirmed.
  • Inference Avatar: the speech LLM drives a causal few-step renderer, audio is the clock, the cascade is the fallback and native duplex is the research track.
  • Streaming renderers: CausVid 9.4 FPS at 1.3 s initial latency (arXiv 2412.07772); Self Forcing 17 FPS on one H100 (arXiv 2506.08009); author-reported, not comparable.

Cascade fallback budget (my illustrative targets, no source):

Stage Illustrative target Inference
Uplink, VAD, end-of-turn 50-150 ms
LLM first token 200-300 ms
Chunker to first clause 50-100 ms
TTS first packet 100-200 ms
Avatar: render first video block 150-250 ms
Total Aim for 500-700 ms median; under 1 s
In the interview, say:

"The target is a unified speech LLM with a text LLM behind a tool call; it owns turn-taking, backchannels and barge-in. The cascade is the baseline: overlapping streams, speculative LLM start at end-of-turn, a small first TTS chunk, and barge-in that truncates context to what was played. Native duplex is the research track, because its data and evals are the long pole."

Trap: the headline number

Quoted figures differ (Tavus claims less than one second between utterances; Synthesia says dialogue is "typically under one second"; Reported) because definitions differ. State where the clock starts and stops, and report p95/p99 under real concurrency.
